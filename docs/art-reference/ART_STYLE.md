# ART STYLE — 角色画风参考（M1 施工依据）

参考图见本目录：`character-female-ref.jpg` / `character-male-ref.jpg`。

## 定位说明

这两张是 **Q 版插画参考**，不是像素图。用法：提取角色设计与配色特征，
由 M1 统一转译成像素 Sprite（目标 32×32 基础网格、PIXEL_SCALE=3 渲染）。
转译时保留「气质」而非临摹细节——头发高光层次、水彩渐变在像素尺度下
收敛为 2–3 阶明度色带。

## 从参考图提取的画风要点

| 维度 | 特征 |
| --- | --- |
| 头身比 | 约 2.5–3 头身，大头小身，幼态比例 |
| 面部 | 大眼（瞳孔大、高光点明显）、小鼻或无鼻、微笑幅度极小（含蓄） |
| 发型（女） | 黑色长侧辫，辫尾缀星形/珠饰，鬓边小花发饰 |
| 发型（男） | 黑色短碎发，蓬松感强，眉眼线条偏锐利 |
| 配色 | 女：米白/奶油裙 + 金星星饰（贴合 cream 主题）；男：深黑大衣 + 暗红领带（贴合 wbrown/ink） |
| 轮廓 | 贴纸张白色描边，造型剪影清晰 |
| 气质 | 温柔治愈系，非搞怪或复古 FC 风 |

## 像素转译规则（M1 执行）

1. 统一 4 方向行走帧（down / up / left / right），左右镜像复用。
2. 眼睛占脸部高度约 1/3，保留单点高光。
3. 每角色主色 ≤ 8 色（含 2 阶阴影），先满足整体色板和谐。
4. 装饰细节（星饰、花饰）降级为 2–3 像素标志性色块，保证小尺寸可辨识。
5. 所有 Sprite 由程序从统一底模生成，禁止逐角色手绘漂移。

## 已确认决策

1. **全世界统一画风**：不只角色，建筑、植被、道具、UI 插画全部沿用此
   温柔治愈系 Q 版气质（奶油底色、柔和水彩感、清晰剪影）。像素转译时
   全资产遵守同一套明度阶与色板规则。
2. **发色 / 瞳色可配置**：参考图的黑发黑瞳为默认皮肤，AI 居民创建时
   发色、瞳色、服饰主色均可自定义，Sprite 由程序按配色参数生成。

## 派生规范（随决策更新）

- 建筑与场景资产与角色共用同一色板梯度：每资产 ≤8 主色、2 阶阴影。
- UI 头像、信箱贴纸、相册插画等 2D 资产按插画风直接绘制（无需像素化），
  与像素场景并存时以「像素场景 + 插画风 UI」为混合基调。
